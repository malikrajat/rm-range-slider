# Project Roadmap

This document outlines the planned features and improvements for `rm-range-slider`. Note that these are subject to change based on community feedback and project priorities.

## Current Focus (v7.x)
*   **Maintenance:** Keeping up with Angular 21 updates and security patches.
*   **Accessibility:** Further refining ARIA support and keyboard navigation.
*   **Customization:** Expanding the set of CSS custom properties for theming.

---

## Upcoming Features

### Short-Term (v7.x / 8.0)
*   [ ] **Vertical Orientation:** Support for vertical slider tracks and thumbs.
*   [ ] **Custom Step Increments:** Improved snapping logic for non-linear steps.
*   [ ] **Step Marks/Ticks:** Visual indicators along the track for major/minor steps.
*   [ ] **Theming Engine:** A more robust set of CSS variables for deep UI customization.

### Medium-Term (v8.x)
*   [ ] **Multiple Handles:** Support for 3+ handles for multi-range selection.
*   [ ] **Custom Thumb Templates:** Allow developers to provide their own HTML for slider thumbs.
*   [ ] **Range Histograms:** Background overlay for showing data distribution along the track.
*   [ ] **Range Presets:** Built-in support for quick-selection buttons (e.g., "Last 7 Days", "Reset").

### Long-Term (v9.x+)
*   [ ] **Native Mobile Wrappers:** Optimized specifically for Capacitor/NativeScript.
*   [ ] **Animation API:** Low-level access to customize the spring/easing physics of thumb movements.
*   [ ] **Advanced Tooltips:** Floating tooltips with custom formatting and template support.
*   [ ] **Full RTL Support:** Refined mirror-imaging for Right-to-Left languages.
